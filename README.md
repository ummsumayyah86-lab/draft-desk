# Draft Desk

Practice desk for marking articles (Fallacies / Political Angle / Testable / Conflict).

## Open
After GitHub Pages is on: `https://ummsumayyah86-lab.github.io/draft-desk/`

On Samsung Tab (Chrome / Samsung Internet): open that link → menu → **Add to Home screen** / **Install app**.

## Share marks with your assistant
Export → Download `.md` → put in OneDrive `Portfolio/Practice/Drafts/`.

No personal name/suburb on the page. No timer.
